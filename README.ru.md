# Game Server Infrastructure

Модульная инфраструктура для самостоятельного размещения игровых серверов с использованием Docker Compose, FRP и публичного VDS.

## Архитектура

- **VDS:** публичная точка входа, FRP-сервер и firewall.
- **Домашний Linux-сервер:** Docker, FRP-клиент и игровые серверы.
- **Mac:** разработка конфигураций и управление Git.

## Игровые модули

| Игра | Статус |
|------|--------|
| Arma Reforger | В разработке |
| DayZ | Планируется |
| IL-2 | Планируется |

## Структура проекта

- `infra/` — общая инфраструктура.
- `games/` — независимые игровые модули.
- `docs/` — общая документация.
- `scripts/` — вспомогательные скрипты.

## Безопасность

Не публикуйте реальные пароли, токены FRP, приватные ключи и файлы `.env`.
